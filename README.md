# MOTO

Management of Transactions and Order for BORG'S Motorcycle Parts and Accessories.

School demonstration target: 30 October 2026. The approved implementation is in progress; module completion is tracked in the implementation plan and execution ledger.

## Local startup

From `C:\xampp\htdocs\moto`, run `powershell -ExecutionPolicy Bypass -File scripts\start-demo.ps1`, then open [MOTO](http://127.0.0.1:8000). The dedicated PHP runtime and MariaDB data directory live in `C:\xampp\moto-runtime`; the database listens only on `127.0.0.1:3307`.

Build local assets with the bundled `pnpm run build`. Run tests with `C:\xampp\moto-runtime\php84\php.exe artisan test`. Read [environment setup](docs/environment.md) for executable paths, migrations, separate database accounts and stopping services. Secrets belong only in local environment/runtime files.

The LPG reference project is separate and remains read-only. The database error encountered during setup and the isolated replacement are recorded in the environment guide.
